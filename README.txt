Squeeze — your personal file toolkit
====================================

Put ALL the files in this folder on any static web host (keep them together):
  index.html, manifest.webmanifest, sw.js, and the four icon PNGs.

After the first visit over https, the page keeps working offline, and you can
add it to your phone's home screen (Share > Add to Home Screen on iPhone,
menu > Install app / Add to Home screen on Android).

Your files are processed on the device you're using. They are never uploaded,
not even to the host where you put this page.

To use it without hosting, just double-click index.html.
